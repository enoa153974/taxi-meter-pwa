# タクシー運行支援 PWA

## このPWAは何か
タクシー運行中に「考える・探す・操作する」回数を減らすための、
タクシードライバー向けに開発している **売上・運行支援PWA** です。  
メインのメーター画面に加え、Firestore を使った売上管理・日別ログ管理・売上詳細表示を実装しています。

---

## 📌 概要

- PWA（モバイル前提・iOS Safari / Android Chrome 対応）
- Firebase Firestore をデータベースとして利用
- バニラ JS（ES Modules）構成
- UI とロジックを分離したシンプルな設計

---

## 主な機能

### 🚖 メインメーター画面
- 現在時刻の表示
- 出勤・帰社・退勤・次回出勤時間の自動計算
- 4:00 切替基準の業務日判定
- 天気表示（位置情報＋OpenWeather API）
- ワンタップ操作用のコントロールパネル
  - 帰宅連絡（LINE）
  - chatGPT
  - Google Map
  - 翻訳（短押し / 長押し）

---

### 運行サポート
- 出勤時間からの稼働時間自動計算
- 京都のタクシー乗り場ライブカメラリンク集

### 天気パネル
- 現在地ベースの天気表示（OpenWeatherMap）
- 30分ごとの自動更新
- PWAが非表示のときは自動更新を停止
- 表示に戻ったら即時更新＋再開


---

### 💰 売上管理（Firestore）

#### 売上データ（sales コレクション）
- 金額（amount）
- メモ（memo）
- 作成日時（createdAt）

**できること**
- 売上登録
- 月度（21日〜翌20日）での集計
- 税込 / 税抜の両方を自動計算

---

### 📝 業務ログ管理（driverLogs コレクション）
- 業務中のメモ・出来事を記録
- 日付単位で自動グルーピング
- 売上メモとは役割を分離して管理

---

## 📊 売上詳細ページ（sales-details.html）

### 表示内容
- 税込合計 / 税抜合計
- 日別売上一覧
  - 日付
  - 税込金額
  - 税抜金額
  - 売上メモ（📝アイコン）
- 日別業務ログ一覧（driverLogs）

### UIの工夫
- 売上メモは **📝アイコンのみ表示**
- メモがある日だけアイコンが出る
- アイコンは Font Awesome を疑似要素（::before）で表示
- 数字を主役にした業務向けレイアウト

---

## 🧠 ロジック設計

### 月度判定
- 基本：21日〜翌20日
- 特例期間をコード内で明示的に管理
- Firestore の createdAt を基準に集計

### 日別集計
- 売上 → 日付ごとに税込 / 税抜を集計
- ログ → 日付ごとに配列で保持
