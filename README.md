# タクシー運行支援 PWA

## このPWAは何か
タクシー運行中に「考える・探す・操作する」回数を減らすための、
タクシードライバー向けに開発している **売上・運行支援PWA** です。  
メインのメーター画面に加え、Firestore を使った売上管理・日別ログ管理・売上詳細表示を実装しています。

---

## 📌 概要

- PWA（モバイル前提・iOS Safari / Android Chrome 対応）
- Firebase Firestore をデータベースとして利用
- バニラ JS（ES Modules）構成
- UI とロジックを分離したシンプルな設計

---

## 主な機能

### 🚖 メインメーター画面
- 現在時刻の表示
- 出勤・帰社・退勤・次回出勤時間の自動計算
- 5:00 切替基準の業務日判定
- 天気表示（位置情報＋OpenWeather API）
- ワンタップ操作用のコントロールパネル
  - 帰宅連絡（LINE）
  - chatGPT
  - Google Map
  - 翻訳（短押し / 長押し）

---

### 運行サポート
- 出勤時間からの稼働時間自動計算
- 京都のタクシー乗り場ライブカメラリンク集

### 天気パネル
- 現在地ベースの天気表示（OpenWeatherMap）
- 30分ごとの自動更新
- PWAが非表示のときは自動更新を停止
- 表示に戻ったら即時更新＋再開


---

### 💰 売上管理（Firestore）

#### 売上データ（sales コレクション）
- 金額（amount）
- メモ（memo）
- 作成日時（createdAt）

**できること**
- 売上登録
- 月度（21日〜翌20日）での集計
- 税込 / 税抜の両方を自動計算

---

### 📝 業務ログ管理（driverLogs コレクション）
- 業務中のメモ・出来事を記録
- 日付単位で自動グルーピング
- 売上メモとは役割を分離して管理

---

## 📊 売上詳細ページ（sales-details.html）

### 表示内容
- 税込合計 / 税抜合計
- 日別売上一覧
  - 日付
  - 税込金額
  - 税抜金額
  - 売上メモ（📝アイコン）
- 日別業務ログ一覧（driverLogs）

### UIの工夫
- 売上メモは **📝アイコンのみ表示**
- メモがある日だけアイコンが出る
- アイコンは Font Awesome を疑似要素（::before）で表示
- 数字を主役にした業務向けレイアウト

## 🧠 ロジック設計

### 月度判定
- 基本：21日〜翌20日
- 特例期間をコード内で明示的に管理
- Firestore の createdAt を基準に集計

### 日別集計
- 売上 → 日付ごとに税込 / 税抜を集計
- ログ → 日付ごとに配列で保持

## 📅 月度期間表示（曜日付き）

売上詳細ページでは、  
**月度判定ロジック（21日〜翌20日）** に基づいた対象期間を  
ページ上部に明示的に表示しています。

### 表示形式
2026.01.21（火） ～ 2026.02.20（木）

markdown
コードをコピーする

### 実装内容
- `getBillingPeriod()` で月度開始日・終了日を取得
- 日付は `YYYY.MM.DD` 形式で表示
- 曜日（日本語）を併記し、直感的に把握できるよう配慮
- Firestore の `createdAt` を基準に、  
  売上・業務ログとも **同一条件** でフィルタリング

### 設計意図
- 「今どの期間の数字を見ているか」を一瞬で理解できる
- 月跨ぎ（20日・21日）でも集計ミスや誤解を防止
- 実運用時の確認コストを最小限に抑えるための UI 表示

## ネタ用 実車メーター演出
実運用とは切り離した 遊び要素 として、
実車ボタンの 長押し操作 によるタクシーメーター風 UI を実装しています。


 - 実車ボタンを 長押し するとネタ用メーター画面を表示
 - 金額は 時間経過のみ でカウントアップ（距離計算なし）
 - 実際のタクシーメーターに近いテンポ感で金額が上昇
 - ボタン操作時に タクシーのスーパーサイン風の電子音 を再生
 - 実機音を録音・加工した音声を使用

## 支払い（停止）操作で以下を表示

 -合計金額
 - 迎車料金などの簡易内訳
 - 「ご利用ありがとうございました」メッセージ

※ 本機能は 完全に演出用・ネタ要素 であり、
　実際の売上計算・Firestore への保存などは一切行いません。

## 🔐 認証（Authentication）について（現状と今後）

### 現在の実装状況（2026-02-07 時点）

本アプリでは **Firebase Authentication の匿名ログイン** を使用しています。

- アプリ起動時に匿名ログインを実行
- 端末ごとに Firebase から `uid` が自動発行される
- Firestore に保存するデータ（売上・ログ）には `uid` を保持している


端末A（iPhone） → uid_A
端末B（PC）     → uid_B

## 🔐 現在の設計方針（Authentication / Firestore）

### データの保存時
- `uid` を記録  
  （将来の認証拡張・ユーザー管理を見据えた設計）

### データの取得・集計時
- `uid` によるフィルタは行っていない
- すべてのデータを対象に集計・表示している

### Firestore セキュリティルール
- 認証済みユーザーのみ `read / write` 可  
  （匿名ログインを含む）
- `uid` による厳密なアクセス制御は現時点では行っていない

---

## この設計を採用している理由

- 現在の主な利用者は 1 名  
  （タクシードライバー本人）
- 将来的に以下の利用ケースを想定しているため
  - 複数端末（スマホ / PC）からの閲覧
  - 家族端末からの確認
- 初期段階で `uid` 制限を厳密にすると
  - 端末ごとにデータが分断され
  - 運用・確認が煩雑になるため
